# 模拟驾驶安全考试（微恐解密网页游戏）

## 项目简介

一个伪装成"科目四模拟考试"的微恐解密网页游戏。玩家表面上是完成交通安全答题，
随着答题推进，题目与画面会逐渐渗入恐怖元素（血迹、白衣女子、坠崖……），
最终通过第 50 题的"回到过去"解锁里线，倒序揭示故事真相。

## 当前进度（2026-08-21）

核心玩法已全部可玩：表线答题 → 50 题交卷回溯 → 里线倒序解谜，全流程闭环。

### ✅ 已完成

#### 基础答题框架
- 开始页 / 答题页双页面结构，顶部工具栏（日夜间切换、声音、动态、重新开始）
- 答对自动进入下一题（1 秒延迟），答错需手动按钮或滑动进入下一题
- 导航规则（见 `txt/规则.txt`）：
  - 上一题 = 左滑 / `←` / "← 上一题"按钮，一定是回到**小序号**
  - 下一题 = 右滑 / `→` / "下一题 →"按钮，一定是到**大序号**
- 键盘支持：`A`–`E` 选择选项，`Enter` 提交/下一题
- localStorage 自动存档，支持"继续考试"

#### 表线（46 题）
- 题号 0–15（判断题）+ 21–50（选择题），跳过 16–20 号段
- 题目数据与 `txt/题目.txt` 一致，见 `js/game-data.js`
- 日间/夜间模式：第 0 题和第 21 题会弹出"是否切换到夜间模式"提示；
  进入里线后无法再切换模式（切回日间会被弹回第 50 题）

#### 恐怖元素渐进（38 题起）
- 血迹系统：38/41/43/48 题入场时血迹等级逐级加深（1–4 级，`#blood-overlay`）
- 白衣女子距离递减：150m → 100m → 50m → 0m → 贴脸
- 特殊题型：
  - `impossible`（43/45 题）：无正确答案，怎么选都是错
  - `sacrifice`（46 题）：任何选择都判定为"放弃"
  - `forced`（47 题）：强制选择后题目配图替换为染血车窗 → 归途
  - `always`（48 题）：所有选项都"可以"
  - `delayed`（49 题）：点击任意选项 4 次后才浮现隐藏选项 E"怨恨"
  - `forced-submit`（50 题）：闭眼交卷，触发结局流程

#### 里线（17 题，倒序）
- 入口：第 50 题交卷 → 夜间模式下点击题干中的"回到过去" → 解锁
- 从 49里 一路"上一题"倒退至 16里，题号显示为"xx里"
- 解锁守卫（`_innerGuardPassed`）：部分里线题需要特定表线条件，
  例如 20里 需表线 0、15 全对；17里 需表线 0–12、15 全对；
  19里/18里 还要求表线 14/13 **故意答错**（剧情设计）
- 答错的里线题只显示错误，不会被弹出；守卫未通过时无法深入

## 技术栈

- HTML5 + CSS3（Flexbox/Grid、动画、日夜间双主题）
- 原生 JavaScript（ES6+，IIFE 模块 + 发布订阅状态机）
- Node.js 内置 test runner（单元测试）

## 使用方法

1. 直接用浏览器打开 `index.html`
2. 点击"开始新考试"（或"继续考试"恢复存档）
3. 表线答完 50 题交卷，夜间模式点击"回到过去"进入里线
4. 里线从 49里 倒退答题至 16里

## 运行测试

```bash
node --test tests/
# 或沙箱限制子进程时直接执行：
node tests/game-engine.test.mjs
```
